# Теория: индекс

Формальные результаты проекта, вынесенные из лабораторного журнала
(`docs/RESEARCH.md`). Каждый файл самодостаточен по модулю определений
файла 01; у каждого результата указан статус (доказано / выведено /
эмпирически / открыто).

| файл | результат | статус |
|---|---|---|
| [01-phase-model.md](01-phase-model.md) | определения: карусель, позиции, окна, Solved, покрытие | язык |
| [02-rotation-invariance.md](02-rotation-invariance.md) | Лемма 1: ожидание не меняет относительных фаз | доказано |
| [03-hole-edibility.md](03-hole-edibility.md) | Лемма 2: съедобность дыры ⇔ пересечение окон стенок | выведено из механики |
| [04-eating-locality.md](04-eating-locality.md) | локальность поедания; бюджет ремонта ~g²/2 | доказано / выведено |
| [05-even-parity.md](05-even-parity.md) | чётная доска: последние дырки в разных долях | доказано |
| [06-necessity-theorem.md](06-necessity-theorem.md) | необходимость композита «путь + окна» при карусели | доказано (мод. K); строгая форма 51/51 |
| [07-conjectures.md](07-conjectures.md) | гипотеза следа, характеризация Solved, потолок честной игры | открыто |

Внешний контекст: Graafsma, Manthey, Skopalik, «Playing Snake on a Graph»
(arXiv:2506.21281), PDF — `data/papers/`. Ревизия нашей модели против
статьи — `docs/RESEARCH.md`, «День 31.07».

Инструменты проверки: `./gradlew covermine` (майнер сертификатов и
покрытия, лестница свободы игрока), `./gradlew policyfairy` (политическая
фея + гейт обучаемости), `EndgameSolver` (точный детектор Solved).
