# Открытые гипотезы и программа

Статусы: [Э] — эмпирически подтверждено (с объёмом), [О] — открыто,
[Ч] — частично доказано. Определения — `01-phase-model.md`.

## 1. Гипотеза следа [Э: 51/51, g ≤ 14]

В решённых конфигурациях малых g слой T теоремы необходимости (файл 06)
покрывается ОДНИМ простым путём в графе свободных клеток. Именно это
превращает разложение теоремы в вычислимый сертификат resid = 0.
Доказательства нет; возможный подход — показать, что при (K) неодиночные
прогоны выигрышного розыгрыша склеиваются в один без потери выигрышности.

## 2. Характеризация решённости (двусторонняя) [Ч]

Целевая форма:

    Solved ⇔ покрывающий путь + окна (необходимость: теорема 06)
           + порядкоустойчивость с ремонтом глубины k* (достаточность)

Измеренная анатомия достаточности (лестница свободы игрока, 31.07,
1917 состояний): чистые «окна + порядок» — 46% решённости; + портфель
походок — 70%; + 1 перекройка — 94%; + 2 — 100%; + 3 — ещё одно
состояние сверх базы. Сходимость по k геометрическая на вид.

Открыто: аналитическая форма слоя ремонта; конечность и величина k*
(гипотетически k* = O(1) при фиксированном g); связь с бюджетом g²/2
(файл 04).

**Важный факт немонотонной интуиции**: решённость — свойство пары
(позиция, свобода игрока). Состояние 800033 (g = 8): слабейший игрок
доказанно проигрывает, база k=2 даёт 0.9905, k=3 доказывает победу.

## 3. Режим (K) как лемма [О]

Доказать, что при g ≤ g₀(m, n) всякий выживающий розыгрыш вынужденно
карусельный (голова следует расписанию освобождения с точностью до
канонических поеданий). Эмпирически — установленный факт №3 журнала.
Их Thm 3.5 доказывает аналог в последних 2-3 клетках нечётного случая.

## 4. Точный дрейф [О]

Строгая форма переноса перевариваемости к моменту S: корпус проходит с
запасом 0, доказано — O(g). Гипотеза: канонические поедания сдвигают
зазоры согласованно, и запас 0 доказуем для одиночных прогонов.

## 5. Solved ⇒ покрытие при больших g [О]

Контрпримеры путевой гипотезы живут при малых g (карусельное кормление
синглтонов). Для программы честности нужен вариант при больших g: раннее
Solved (= чит по Определению 1 формализации) требует c(S) ≈ 1. Связь с
Θ-структурами их Lemma 3.4.

## 6. Теорема о потолке честной игры [О — главная цель]

Программа (журнал, «формализация честности», 31.07):
- скаляры без намерения: гарантированное якорное покрытие I_c
  (чит = ранняя гарантия c ≈ 1) и заполнение входа в решённость φ_solve
  (детектор — сертификаты решателя; честные боты: 98.4%+, читы: 0);
- скелет: финал требует c = 1; скорость набора покрытия ограничена
  локальностью (файл 04); недостающее звено — антиконцентрация: стратегия
  без гарантии теряет покрытие под равномерными костями с вероятностью
  ≥ p за эпоху;
- целевая форма: P(win | без раннего I_c) ≤ f(n) → 0. Эмпирические якоря:
  фея (60 / 200+ согласованных спавнов), скейлинг честных полных партий
  24% → 7% → 2-3% (15×15 / 30×30 / 60×60).

## 7. Вероятностная плотность съедобности [Э-эвристика]

P(дыра со случайными фазами стенок съедобна) ≈ 12g/L при k = 4 стенках
(файл 03). Использовать как кирпич в п. 6 (антиконцентрация): глубокая
некоррелированная дыра почти наверняка смертельна.

## 8. NP-membership подкласса [О]

Если п. 2 замкнётся конечным k*, сертификат решённости карусельных
конфигураций становится полиномиально проверяемым — вклад в открытый
вопрос NP-принадлежности snake-winnability (arXiv:2506.21281, §3).
