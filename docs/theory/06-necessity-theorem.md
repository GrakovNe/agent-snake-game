# Теорема необходимости композита (карусельный режим)

Статус: **доказано** по модулю явно выписанных гипотез (K) и переноса с
запасом; строгая (с нулевым запасом) форма — **эмпирически 51/51** на
решённом корпусе g ≤ 14 (200 партий 30×30, майнер CoverMine, 31.07).

Определения — `01-phase-model.md`; Леммы 1–2 — файлы 02, 03.

## Гипотеза (K): карусельный режим

Между поеданиями голова следует расписанию освобождения (едет за
хвостом); розыгрыш остаётся в этом режиме до конца партии. Эмпирическое
основание — установленный факт №3 журнала (глубокий эндшпиль — карусель).
Статус K как леммы — открыт (файл 07).

## Теорема

Пусть конфигурация S решена (Solved) и всякий выигрышный розыгрыш из S
подчинён (K). Тогда свободные клетки F(S) разлагаются

    F = T ⊔ Q ⊔ R,

где T — объединение клеток неодиночных прогонов головы по F (каждый
прогон — связная прогулка в графе свободных клеток), каждая q ∈ Q
оконно-перевариваема (Лемма 2) в момент своего съедания, |R| ≤ 1.

## Доказательство

**1. Розыгрыш.** S решена ⇒ для любой последовательности спавнов σ
существует выигрышный розыгрыш π. Зафиксируем любую σ и π. Розыгрыш
съедает ≥ g − 1 клеток F (цель N−1); положим R = несъеденное, |R| ≤ 1.

**2. Разложение на прогоны.** Ограничим траекторию головы на такты
пребывания в клетках F и разобьём на максимальные по времени прогоны.
Внутри прогона соседние по времени клетки смежны на сетке (один ход) и
обе лежат в F ⇒ каждый прогон — прогулка в графе свободных клеток S.
Каждая съеденная клетка принадлежит какому-то прогону: голова стоит на
ней в момент съедания. T = клетки неодиночных прогонов, Q = клетки
одиночных.

**3. Одиночные прогоны — канонические поедания Леммы 2.** Пусть {q} —
одиночный прогон: голова вошла в q с клетки b₁ тела S и вышла на клетку
b₂ тела S; обе смежны q, т.е. являются стенками дыры q. При (K) голова
стоит на b₁ в такт t = p(b₁) + g своего расписания (конец окна клетки
b₁). Выход в b₂ — через два такта (вход-съел-вышел): требуется
свободность b₂ в такт t + 2, то есть t + 2 ∈ W(p(b₂)):

    p(b₂) ≤ p(b₁) + g + 2 < p(b₂) + g.

Это в точности условие W(p_i) ∩ W(p_j − 2) ≠ ∅ Леммы 2 для стенок
i = b₁, j = b₂. Значит q оконно-перевариваема в фазовой конфигурации
момента съедания. ∎

**4. Перенос к моменту S (лемма о дрейфе, с запасом).** Сертификат
CoverMine проверяет перевариваемость в фазах S, а не момента съедания.
При (K) между поеданиями фазы жёстки (Лемма 1); каноническое поедание —
вставка одной клетки в петлю, меняющая круговой зазор любой
фиксированной пары стенок не более чем на 1 (точка вставки либо внутри
дуги между ними, либо нет). После e ≤ g поеданий суммарный дрейф ≤ g ⇒
перевариваемость в момент съедания влечёт перевариваемость в S с
запасом O(g) по ширине окна. ∎

## Что НЕ доказано (см. файл 07)

- **Гипотеза следа**: T покрывается ОДНИМ простым путём. Эмпирически —
  100% на корпусе g ≤ 14 (это и даёт resid = 0), доказательства нет.
- **Строгий перенос**: корпус прошёл проверку с запасом 0, доказанная
  граница — O(g). Точный дрейф открыт.
- **Сама (K)** при малых g — эмпирический факт, не лемма.

## Эмпирический статус и контекст

- Композитный остаток resid = 0 у всех 51 известных Solved-состояний
  (50 базовых сертификатов + 1 состояние, сертифицированное только при
  k = 3 перекройках). Ни одного Solved с resid ≥ 1 не найдено.
- Обратное направление (достаточность) заведомо слабее: 80.6% доказанных
  проигрышей тоже имеют resid = 0 — обречённость живёт во временнóй
  композиции окон и в слое ремонта (лестница свободы, журнал 31.07;
  файл 07).
- Родственный результат: теорема 3.5 Graafsma–Manthey–Skopalik — прототип
  необходимости структуры для нечётных двудольных графов (адверсариальный
  плейсер); наша теорема — карусельный аналог на уровне механики
  поеданий.
