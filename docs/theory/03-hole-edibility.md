# Лемма 2: критерий съедобности дыры (окна стенок)

Статус: **выведено из механики движка**; тайминговый вывод независимо
воспроизведён в доказательстве теоремы необходимости (файл 06, шаг 3);
эмпирически несущий элемент (объясняет 9/9 нарушителей путевой гипотезы;
композит с ним — 51/51 на Solved-корпусе).

Определения — `01-phase-model.md`.

## Формулировка

Дыра h со стенками позиций p_1..p_k съедобна в карусели ⇔ существуют
стенки i ≠ j с пересекающимися окнами

    W(p_i) ∩ W(p_j − 2) ≠ ∅,

то есть круговое расстояние между p_i и p_j − 2 меньше g (в одну из
сторон). Вход в дыру — через стенку i в её окно, выход — через стенку j
двумя тактами позже; сдвиг −2 — точная поправка механики
«вход-съел-вышел».

**Особый случай**: последняя свободная клетка (g = 1) съедобна
безусловно — выход не нужен. База индукции полного поля.

## Вывод из механики (тайминг расписания)

Голова, едущая по расписанию освобождения, стоит на клетке стенки i в
такт t = p_i + g (конец окна этой клетки). Вход в h — такт t + 1,
поедание удерживает хвост один такт, выход в клетку стенки j — такт
t + 2, что требует её свободности: t + 2 ∈ W(p_j), т.е.

    p_j ≤ p_i + g + 2 < p_j + g.

Это в точности условие пересечения окон выше. ∎ (Подробный контекст —
файл 06, шаг 3.)

## Следствия и замечания

1. С Леммой 1 (файл 02): несъедобность — вечный приговор в замёрзшей
   фазе; критерий проверяется за O(k²) на дыру, O(N) на конфигурацию.
2. Перевариваемость определяется парой стенок, а не всеми четырьмя:
   дыре достаточно одного согласованного входа-выхода.
3. Критерий локален по фазам, но НЕ переносится автоматически через
   поедания: каждое поедание сдвигает фазы (лемма о дрейфе, файл 06,
   шаг 4). Статическая проверка в момент S — приближение, оказавшееся
   на корпусе точным (запас 0), что сильнее доказанного переноса.
4. Вероятностная оценка плотности (эвристика, журнал «матан-сессия»):
   для случайных фаз стенок P(съедобна) ≈ C(k,2)·2(g+2)/L ≈ 12g/L при
   k = 4 — объяснение, почему глубокая дыра со случайными стенками
   почти наверняка смертельна и почему выживание требует
   пространственно-локальной траектории.
