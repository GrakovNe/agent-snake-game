# Состояние проекта: история решений, архитектура, вектор

Снапшот на 2026-07-31. Хронология с полными цифрами — `RESEARCH.md`;
формальные результаты — `theory/`; человеческое изложение — `research-ru.md`;
эксплуатация — `RUNBOOK.md`.

## Цель и правила

Бот, стабильно доедающий поле 60×60 (счёт 3599+). Гамильтонов цикл —
статический или динамически чинимый — запрещён как чит. Разрешены: поиск
по текущему состоянию, тюнинг эвристик, ML. Генератор еды — равномерный
случайный; движок детерминирован по сиду.

## История поиска решений

### Принятые решения (живут в текущем боте)

| решение | вклад |
|---|---|
| SafeGreedy: кратчайший путь к еде + статическая достижимость хвоста после виртуального съедения | база выживания; 60×60 mean 3575 |
| Приёмка еды: статика ИЛИ timed-побег со статически безопасным концом | +устойчивость приёмки |
| Пер-тиковый хаос стойла (без коммитов), 4 формы обхода | лучший генератор траекторий из всех проверенных |
| Щит перевариваемости в момент еды (счётчик неизлечимых дыр не растёт) | защита от вечных дыр |
| Широкий снапшот-пул путей в эндшпиле | последний эвристический прирост (30×30 → ~40%) |
| Эпизодный поиск сидов с CRN (best-of-4, 3 роллаута, зона 40 клеток) | первые целевые игры на 60×60 (2-3%) |
| Нейро-оценщик продолжений (ONNX value net) вместо роллаутов | паритет при 2-3× меньшем компьюте |
| Точный решатель эндшпиля (сертификаты побед, зона ≤14 клеток) | не добавляет побед, но доказывает их |

### Отброшенные решения (полный список опровержений)

Эвристики (турниры, раунды 1-7): коммит стойла в миттельшпиле, запрет
клеток вокруг еды, щит мёртвых клеток, timed-кандидаты первой линии,
перебор фаз ожидания (математически пуст — Лемма 1), beam-детуры
«ноль неперевариваемых дыр», spawn-минимакс на последних клетках.

Оценщики (раунды 8+, десять опровержений на 200-400-игровых замерах):

| # | ветка | вердикт |
|---|---|---|
| 1-5 | турнирные кнобы выше | шум или вред |
| 6 | value-функция формы петли (ridge, 40k игр) | различает состояния, не кандидатов |
| 7 | TD / fitted value iteration (v8) | 60×60 2.0% против базы 2.3% |
| 8 | ёмкость сети ×10 (v9, лучшая валидация в истории) | бит-в-бит с v8: разрешение — не бутылочное горлышко |
| — | big-k (best-of-16/32, оба оценщика) | ≈ best-of-4: дисперсия — случайное блуждание, не выбираемые ветки |
| — | хореография-кнобы, sortstall/sorteats, holerank, repairguard, neuralstall, band/lanes | плоско или хуже; сортировка — верный диагноз без рычага |
| 9 | точный экспектимакс последних 6-14 клеток | хаос уже выжимает всё; судьба решена раньше |
| — | отключение голода (×10/×50) | таймер не ограничивает; потолок — геометрия |
| 10 | дообучение на «последнем правильном ходе» (политическая фея + гейт) | преимущество хода не переживает переброс кубиков (Δ = −0.6 п.п., плацебо-уровень) |

Незакрытый хвост инженерии: v10 (ExIt на 254k on-policy состояний) —
харвест собран, обучение не доведено (облако остановлено). Ожидание по
всем прецедентам — плоско.

## Текущая модель решения

### Архитектура бота (SafeGreedyStrategy, пресеты sweep/episodes/neural)

1. **Первая линия**: кратчайший путь к еде; приёмка — статическая
   достижимость хвоста после виртуального съедения (плюс timed-побег как
   lastResort).
2. **Стойло**: пер-тиковый хаотичный выбор из четырёх форм обхода,
   без коммитов; закоммиченные пути только для верифицированных побегов.
3. **Щит еды**: поедание отклоняется, если растит число неперевариваемых
   дыр (критерий окон, Лемма 2).
4. **Эндшпиль (≤40 свободных)**: эпизодный поиск — точный реплей эпизода
   до поедания, best-of-4 вариантов RNG, оценка продолжений CRN-парами
   роллаутов (episodes) или нейро-оценщиком (neural).
5. **Финал (≤10-14 свободных)**: точный решатель; коммит только
   сертифицированных побед.

### Научная модель (фазовая теория, `theory/`)

Глубокий эндшпиль — карусель: тело — замкнутая петля, свободные клетки —
синглтоны с фазовыми окнами. Доказано/выведено: инвариантность фаз при
ожидании; критерий съедобности дыры; локальность поедания и бюджет
ремонта ~g²/2; чётная лемма о последних дырках; теорема необходимости
композита «путь + окна» (строгая форма — 51/51 на корпусе).
Причинность потолка установлена феей: спавны → фрагментация → результат;
переброс ~60 согласованных спавнов (30×30) превращает поражение в победу,
переигровка ходов — нет.

## Текущие проблемы

1. **Потолок принадлежит кубикам, не политике** — девять опровержений
   оценщиков/генераторов плюс прямой контрфактический A/B хода (десятое).
   Честные 2-7% полных партий — вероятность самопроизвольной
   низкофрагментированной линии.
2. **Кандидаты вырождены**: в решающей зоне (95-97% заполнения) выборы
   бит-идентичны для оценщиков любой точности; точный перебор там
   невычислим.
3. **Достаточность решённости не характеризована**: статический
   сертификат — идеальная необходимость, но 80% обречённых его тоже
   проходят; обречённость живёт в порядке и ремонте.

## Открытые гипотезы (ранжир — `theory/07-conjectures.md`)

Математика: гипотеза следа (один простой путь), точный дрейф, режим
карусели как лемма, конечность глубины ремонта k*, Solved ⇒ покрытие при
больших g, антиконцентрация → теорема о потолке честной игры,
NP-membership подкласса. Инженерия: направленная фея (интервенционный
тест причинности), покрывающий планировщик (единственный незакрытый
класс генераторов).

## Вектор развития

Проект мигрировал из инженерии в науку. Три дорожки по убыванию
готовности:

1. **Математика** (активная): замкнуть след + дрейф → теорема
   необходимости становится безусловной (в пределах K) → math-заметка
   «анатомия решённых эндшпилей» со стыковкой к открытому NP-membership.
   Дальний приз — теорема о потолке честной игры.
2. **Публикация**: research-ru.md прошла два раунда слепого ревью и
   готова; STATE и theory дают материал для англоязычной заметки.
3. **Инженерия** (почти закрыта): направленная фея дёшева и полезна как
   эксперимент; покрывающий планировщик — единственная ставка на сдвиг
   игровых процентов, дорогая и с неясным шансом.

## Куда двигается сложность

Траектория сложности за проект: эвристики (часы) → турниры (дни) →
эпизодный поиск (CRN, недели) → ML-конвейер (GPU-облако) → точные
решатели → контрфактические инструменты → формальная математика.

Три наблюдения о её характере:

1. **Инженерная сложность бота вышла на плато и там останется.** Сам бот
   не растёт с раунда 9: всё добавленное после — сертификаты и
   инструменты, не поведение. Каждый следующий игровой процент требовал
   на порядок больше компьюта и десять раз подряд оказывался нулём;
   рациональная цена дальнейших инженерных попыток — только
   планировщик-класс, то есть качественно новая архитектура, а не
   наращивание текущей.
2. **Сложность инструментов доказательства растёт экспоненциально по
   зоне.** Точный решатель упирается в бюджет уже при 14 клетках;
   лестница ремонта дорожает с k; любые «ещё точнее» замеры — это
   комбинаторные взрывы. Единственный способ её сжать — теория:
   полиномиальный сертификат (характеризация с конечным k*) заменил бы
   перебор.
3. **Остаточная сложность — комбинаторно-математическая.** Открытые
   вопросы больше не решаются машиной времени: след, дрейф, K,
   антиконцентрация — задачи на доказательство, где корпуса и майнеры
   служат проверкой гипотез за секунды, а не источником результата.
   Проект в точке, где дешевле думать, чем считать, — впервые за свою
   историю.
